# Branch Exercise

This file is optional extra practice. During the main workshop, use the branch `feature/my-change` as described in `README.md`.

To practise switching branches after your work is committed:

```bash
git branch
git switch main
git branch --show-current
git switch feature/my-change
git branch --show-current
```

- `git branch` lists local branches; `*` marks the active one.
- `git switch main` moves to `main`; do this when your working tree is safe to switch.
- `git branch --show-current` tells you exactly which branch is active.
